# PR・コミット作成方針

PRタイトルとコミットメッセージには、後述の接頭辞を使用する。

PRタイトルとPR本文、コミットメッセージは日本語で記載する。

基本的に https://www.conventionalcommits.org/en/v1.0.0/ に記載される方式に従う。

接頭辞として使うキーワードを以下に列挙する。

|接頭辞|説明|
|---|---|
|fix|既存の機能の問題の修正時に使用。|
|feat|新しい機能の追加時に使用。|
|change|仕様変更により、既存の機能に修正を加えた場合に使用。|
|refactor|外部から見た動作や公開APIの契約を維持しながら内部構造を整理する場合に使用。|
|delete|ファイル削除時・機能削除時に使用。|
|rename|ファイル名変更時に使用。|
|move|ファイル移動時に使用。|
|revert|以前のコミットに戻す場合に使用。|
|docs|ドキュメント修正時に使用。|
|style|コーディングスタイル修正時に使用。|
|test|テストコード修正時や、テストコード追加時に使用。|
|chore|ビルドツールやライブラリで自動生成されたものをコミット時や、上記の接頭辞に該当しない該当しない変更時に使用。|
